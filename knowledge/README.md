# 四个业务Agent演示知识资产

版本：v1.1  
基线日期：2026-08-17  
适用范围：AG-001、AG-012、AG-025、AG-027工程样例

本目录用于管理四个当前Agent工程样例的知识资产。除已单独标识的国务院官网公开条例摘录外，其余内容均为项目自编虚构演示材料，不代表真实商品、政策、标准、指标、平台规则或正式业务数据。

## 目录结构

- `catalog.json`：运行时使用的统一知识档案，是本目录的机器可读清单；
- `四个业务Agent_演示知识资产清单_20260817_v1.0.md`：供项目评审使用的中文资产台账；
- 当前四个Agent子目录对应产品参数、政策标准、客服知识、指标字典和分析治理材料；AG-002、AG-003目录仅保留为未注册参考材料，不进入`catalog.json`和运行索引。

## 治理口径

1. 每项知识均具有唯一知识编号、适用Agent、来源性质、版本、生效信息、密级、状态和维护责任信息。
2. `record_ids`把运行时预解析记录映射到正式知识档案，保证页面引用与RAG实际入库一致。
3. 当前统一使用`公开演示`密级；正式业务资料接入后必须根据甲方身份、租户和角色体系重新配置。
4. 生命周期分为`published`、`superseded`、`withdrawn`。历史版本可用于版本比较，但不得表述为当前有效依据。
5. 文档发布前应完成人工校核；更新、撤回和替换必须同步更新目录版本并重新执行黄金集评测。

## 责任边界

我方负责业务Agent所需知识分类、检索策略、证据约束、引用规则和验收问题。甲方AI中台最终负责公共知识基础设施、向量/全文检索及平台级治理；数据和业务系统合作方负责权威业务数据、正式状态及执行结果。
