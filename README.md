# 景德镇低空商业服务网 Agent 能力展厅 v1.9

面向甲方展示五个标杆业务 Agent 的前端能力展厅与统一演示工作台。

## 当前包含

- AG-001 低空产品型号对比Agent：可运行。
- AG-002 低空产品说明书解读Agent：可运行。
- AG-003 低空产品分类导购及推荐Agent：可运行。
- AG-012 政策、标准解读Agent：可运行。
- AG-025 智能客服Agent：可运行。

页面当前明确使用样例知识与演示数据，不代表正式业务数据、正式联调结果或生产验收结论。

## AG-001 当前可运行能力

- 使用 LangGraphJS 编排需求理解、产品检索、参数归一、约束判断、比较分析和结果校验。
- 对齐当前 v2.14 需求表与 v3.41 功能导图中的12项 AG-001 能力，输出同时保留稳定功能编号和纯数字上位需求编号来源。
- 支持指定型号比较，也可按用途、预算、续航、载荷、抗风、交付及质保条件筛选样例产品。
- 先对完整候选集执行硬约束判断，再限制展示数量，避免遗漏满足条件的型号。
- 支持复合业务场景；单型号直接比较和缺少单位的预算会进入澄清分支。
- 输出可切换的横向/纵向参数表、候选评分、优势、短板、场景适配、条件冲突、首选和备选方案。
- 当全部候选违反硬约束时拒绝强行推荐；未通过硬约束的候选不会显示为高分可推荐方案。
- 自动保存最近5条当前浏览器本地演示记录，可回看和复用。
- 所有产品均为虚构 Mock 数据，通过 `BusinessDataPort` 提供。

## AG-002 当前可运行能力

- 使用独立 LangGraphJS 工作流编排问题理解、样例文档加载、文档结构解析、证据检索、证据充分性判断、通俗化指引、风险校验和带依据输出。
- 对齐当前 v2.14 需求表与 v3.41 功能导图中的13项 AG-002 能力；11项通过样例演示，图示理解和章节图表关系理解2项保留正式适配边界。
- 场景语义检索、说明书图示含义解读、说明书章节与图表关系理解明确标记为正式 AI 中台适配预留，不把规则检索和预解析材料描述为真实 OCR 或多模态效果。
- 可按飞行前检查、充电、维护、定位漂移、失控与返航等场景检索样例说明书。
- 输出分步操作指引、适用条件、安全注意、风险标记、通俗术语解释、章节页码和相关原文摘要。
- 涉及飞行、安全、故障或合规的结果自动标记为需要人工复核，不将样例手册答复作为正式操作指令。
- 无直接证据的问题进入澄清分支，不使用主题相近但业务无关的章节拼接答案；AG-002 文档编号采用专属上下文校验。
- 当前仅使用虚构的预解析样例说明书；正式 PDF、扫描件、OCR、多模态识别和文档库通过 `AIPlatformPort` 与 `DocumentDataPort` 接入。

## AG-003 当前可运行能力

- 使用独立 LangGraphJS 工作流编排导购意图理解、能力边界检查、样例目录加载、硬条件筛选、候选排序、适用性/差距核验和推荐依据生成。
- 对齐当前 v2.14 需求表与 v3.41 功能导图中的50项 AG-003 能力；13项商城场景方案和商品搜索能力通过 Mock 目录演示，图片找货、二手推荐和内容审核等37项保留正式适配边界。
- 支持山区电力巡检等成套场景方案推荐，也支持按用途、预算、抗风、续航、载荷、新手经验和型号搜索条件推荐商品。
- 搜索支持样例型号识别与有限纠错；显式型号作为目标约束，目标不满足条件时停止推荐，并把其他可行产品明确列为替代候选，不再静默顶替。
- 同时识别“续航至少50分钟”和“至少续航50分钟”等前后语序，保留小数预算精度，并区分正向、非重点和排除型偏好。
- 商品搜索仅加载商品目录，场景方案推荐仅加载方案目录，避免无关接口故障拖垮当前路径。
- 场景方案的适用场景、实施能力和新手/专业条件实际参与判断，并进入前端候选说明。
- 输出首选、备选、评分、目标匹配状态、匹配标签、适用条件、推荐理由、限制、差距、待确认数据和规则版本。
- 图片找货相关11项能力，以及依赖真实用户行为、卖家信用、在售状态和同城可达性的9项 C2C 能力，明确标为 `adapter-ready`；当前不伪造视觉识别或个性化效果。
- 当前仅使用7个虚构产品和3套虚构场景方案；正式目录、库存、价格、商品状态及实施条件通过 `BusinessDataPort` 接入，视觉与语义能力通过 `AIPlatformPort` 接入。

## AG-012 当前可运行能力

- 使用独立 LangGraphJS 工作流编排政策问题理解、样例政策库加载、版本时效核验、条款检索与重排、证据充分性判断、版本变化分析、适用条件拆解和复核边界校验。
- 对齐当前 v2.14 需求表与 v3.41 功能导图中由 AG-012 承载的66项能力：其中23项政策咨询、依据检索、版本关系和适用条件能力通过 Mock 样例演示；空域政策、跨库关联、专业内容审核及适航相关43项能力如实标为正式适配边界。
- 支持政策与标准要点摘要、带依据问答、新旧版本对比、政策适用条件辅助判断和业务影响分析。
- 按请求发生日或用户明确时点动态区分当前有效、待生效和已失效版本；严格校验日期和“以前、以后、截至”等时间方向，不会把发布日期更新但尚未生效的文件误当成现行依据。
- 显式文档编号优先于文本别名；版本比较只沿命中材料的同一版本链展开，资料不足时追问，不使用其他政策的版本变化代替。
- 输出文号、发布机构、版本、生效状态、条款定位、原文摘要、版本变化类型、业务影响和待核实事项。
- 适用性判断拆分地区、主体、业务场景和版本时效，并要求主体与场景在同一条款依据上联合成立；涉及主管部门口径或专业判断时自动标记人工复核。
- 样例库没有直接依据时停止生成结论；适航问题不伪造权威资料或合规结果，直接进入正式资料与专业复核适配边界。
- 当前仅使用两个虚构政策版本和一份虚构行业标准；正式政策库、标准库和适航资料通过支持受限搜索、按编号取文档和按版本链取文档的 `PolicyDataPort` 接入，避免每次加载完整语料库；语义理解与检索重排通过 `AIPlatformPort` 接入。

## AG-025 当前可运行能力

- 使用独立 LangGraphJS 工作流编排会话上下文加载、咨询意图识别、缺失信息追问、知识与业务工具调用、依据重排、客服答复生成、人工介入判断和会话摘要保存。
- 对齐当前 v2.14 需求表与 v3.41 功能导图中由 AG-025 主承载或协同承载的56项能力：其中19项多意图识别、FAQ答复、订单/商品/服务关联、转人工判断和会话摘要能力通过 Mock 演示，其余37项商品搜索协同、跨板块协同、运营问数、违规风险、即时沟通内容风险识别、信用影响及金融咨询能力保留正式适配边界；每项均保留稳定功能编号和与0723V2一致的纯数字需求编号来源。
- 支持平台规则、商品咨询、订单状态、物流异常、售后流程、飞行/技术/商业服务、投诉和明确转人工等多类意图。
- 订单查询只按唯一订单号执行；正文与上下文订单号冲突、缺少订单号、提供多个订单号或 Mock 库未命中时进入澄清，不读取或替代为其他订单。
- 支持在同一`session_id`内复用已经确认的订单、商品和服务上下文，并生成当前问题、已确认信息和处理轨迹摘要；Demo使用有容量上限的进程内会话适配器，正式环境必须替换为业务系统会话存储。
- 投诉场景结构化提取问题主题、涉及对象、发生时间和核心诉求；“不要、无需、暂不转人工”等否定表达不会被当作明确转人工请求。
- 产品选型路由到 AG-003；飞行、技术和商业服务路由到相应专业服务；当前只输出路由建议，不声称已完成跨 Agent 调用或真实转接。
- 投诉、融资、信贷、违规风险、信用影响及运营问数进入人工或专业能力边界，不生成审批、处罚、授信、信用处理或因果分析结论。
- 输出意图板块、问题类型、置信度、路由路径、知识依据、工具结果、转人工目标、优先级、已确认信息和待处理事项。
- 当前使用6条虚构 FAQ、2个虚构订单、2个虚构商品和3项虚构服务指引；正式知识、订单、商品、服务和转接机制通过 `CustomerServiceDataPort` 及应用系统接入。正式订单查询端口要求服务端传入可信用户、租户和角色授权作用域，不采用请求正文中的自报角色作为鉴权依据。

## 技术底座

- `AgentRequest`、`AgentResponse`及比较结果均使用 Zod 进行运行时校验。
- 每个 Agent 使用独立 `Provider Registry` 注入 `AIPlatformPort`、`BusinessDataPort`、`DocumentDataPort`、`PolicyDataPort` 或 `CustomerServiceDataPort`；AG-002、AG-003、AG-012、AG-025 Provider 均延迟解析并隔离配置故障，不影响其他 Agent 和页面启动。
- `DocumentDataPort`只交付文档元数据和原始文档制品引用，OCR、版面解析、检索与重排由`AIPlatformPort`承载，Agent工作流负责业务意图、证据门控、场景化生成与安全复核。
- 端口调用具备超时、有限重试和熔断保护；前端请求支持超时和切换 Agent 时主动取消。
- 每次调用分别生成`request_id`和`trace_id`，服务端输出不包含用户问题正文的结构化运行日志。
- 浏览器会话使用独立随机`session_id`，不在不同用户之间共享演示上下文。
- 规则版本、权重、场景默认维度及候选数量集中配置在`AG001_CONFIG`。

## 接口

- `GET /api/agents`：Agent目录和可运行状态。
- `POST /api/agents/:agentId/invoke`：统一Agent调用接口，采用运行时校验的`AgentInvokeRequest`和`AgentInvokeResponse`契约。
- `GET /api/data/products`：AG-001 Mock产品诊断接口，可按`ids`或`scenario`查询。
- `GET /api/data/manuals`：AG-002 Mock说明书目录诊断接口，可按`id`查询。
- `GET /api/data/solutions`：AG-003 Mock场景方案目录诊断接口，可按`scenario`查询。
- `GET /api/data/policies`：AG-012 Mock政策与标准目录诊断接口，可按`id`或`type`查询。
- `GET /api/data/customer-service-knowledge`：AG-025 Mock FAQ 与规则目录诊断接口。
- `GET /api/data/customer-orders?id=JDZ-DEMO-1001`：AG-025 单订单 Mock 查询接口；不提供订单列表。
- 未实现的数据资源返回`404`，避免把接口路径错误伪装为空数据。
- 浏览器固定调用同源`/api` BFF；正式AI能力和业务数据均由服务端适配器访问，不允许前端通过公开环境变量绕过我方接口层。

## 本地运行

```bash
pnpm install
pnpm run dev
```

生产构建：

```bash
pnpm run build
```

运行自动化回归：

```bash
pnpm run test
```

运行全部质量门禁：

```bash
pnpm run check
```

当前仍属于 Mock 阶段成果，不代表正式三方联调、真实数据效果或生产验收。

## 商业化运行基线

演示模式继续使用隔离的 Mock Provider；生产模式不会回退 Mock。当前已具备可信网关签名身份、租户隔离、五个 Agent 的版本化生产适配器、D1 会话与运行审计持久化、分布式限流与月配额、幂等请求保护，以及输入注入、工具白名单、上游数据分级/来源校验和输出泄露拦截。正式启用条件、环境变量与上游协议见 `.env.example` 和 `docs/PRODUCTION_ADAPTER_CONTRACT.md`。

五个 Agent 现已通过统一 Runtime 注册表管理请求/响应契约、访问策略、总时限、执行模式与版本；公共 AI、领域数据、可信访问上下文和工具执行端口已抽取。生产运行同时支持取消向下游传递、分类重试、指数退避与抖动、D1 分布式熔断、异步任务队列、回调去重，以及客户可见处理步骤与内部技术 Trace 分离。前端展厅与独立 Runtime 入口共享同一处理器，部署说明见 `docs/COMMERCIAL_RUNTIME_ARCHITECTURE.md`，Cloudflare 独立部署样例见 `wrangler.agent-runtime.toml.example`。
