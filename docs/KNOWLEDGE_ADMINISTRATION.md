# Agent 知识管理能力说明

## 建设范围

`/knowledge-admin` 是四个业务 Agent 工程样例的内部知识管理工作台，负责 Agent 侧知识分类、来源登记、元数据治理、分块预览、审核、索引发布、撤回、版本回滚、有效期提醒、解析异常监控和问答抽样复核。

该能力不替代甲方 AI 中台的通用 OCR、Office/PDF 解析、向量基础设施和统一权限平台；也不替代数据中台及业务系统对权威业务数据、实时状态和正式业务执行的管理。

## 生命周期

1. 登记：记录 Agent、标题、知识领域、来源单位、来源性质、版本、生效期、保密等级、可见角色和审核责任人。
2. 解析：TXT、Markdown、JSON、CSV、TSV 在当前 Agent 侧演示解析；PDF、Office 和图片登记为“等待外部解析”，不伪造 OCR 结果。
3. 审核：解析完成的草稿才可提交审核。
4. 发布：审核通过后写入对应 Agent 的受控 RAG namespace，生成不可变索引版本。
5. 撤回：从当前检索索引删除，但保留资产、修订和发布审计记录。
6. 回滚：仅对已撤回资产开放，恢复历史快照并重新发布新索引版本。

## 运行与持久化

- 本地演示默认使用进程内存，重启后新登记资产会重置为15项基线知识档案（1项国务院官网公开法规摘录、14项虚构演示材料）。
- 绑定 D1 后，管理快照写入 `knowledge_admin_snapshots`，RAG namespace 快照写入 `rag_namespace_snapshots`。
- 生产模式通过可信网关身份校验，仅 `admin` 或 `knowledge-admin` 角色可操作。
- Demo 管理入口仅允许回环地址，并对变更请求校验同源 `Origin`；该约束不作为生产鉴权替代。

## 验收重点

- 发布后，Agent 检索链路能召回新知识并返回知识编号、版本和生命周期。
- 撤回后，当前索引不再召回对应资产。
- 回滚后，历史内容重新进入索引且产生新的发布审计记录。
- 解析失败、依赖外部解析、临期与过期资产可在治理提醒中集中查看。
- 每个当前工程样例 Agent 至少配置一条问答抽样任务，可记录通过或未通过及复核人。

当前所有基线知识均为项目自编虚构演示材料，不代表甲方正式业务知识或生产验收结论。
