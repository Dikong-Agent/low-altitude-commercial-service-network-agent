# 旗舰业务Agent接入契约

更新时间：2026-08-14

## 1. 适用范围

本文定义AG-012政策、标准解读Agent与AG-025智能客服Agent接入甲方AI中台、数据中台及业务系统时的最小契约。当前工程样例验证的是Agent侧业务编排、证据门控和安全边界，不代表甲方AI中台或正式业务接口已经完成。

## 2. 共同调用与返回

请求使用统一AgentRequest：agent_id、input、session_id和场景上下文。服务端生成request_id与trace_id，返回状态、业务结果、证据、处理步骤和实际工作流轨迹。

AI中台适配端口应提供：

- parseIntent：结构化语义理解，可选；不可用时Agent使用确定性规则安全降级。
- embed：批量文档及查询向量，返回模型与版本。
- rerank：按查询重排候选证据，返回相关度。
- generateGroundedAnswer：只能基于传入证据生成逐声明引用的结构化答案。

所有调用必须支持超时、错误码、链路标识和模型版本；返回Token、耗时、降级阶段及校验错误。生成失败时允许退化为“证据列表+确定性业务结论”，不得无依据补写。

## 3. AG-012政策、标准解读Agent

输入包括问题、查询时点和可选文档编号。PolicyDataPort最少提供：

- 受限搜索：按类型、主题、地区、主体、场景、时效和权限过滤。
- 精确取文档：按正式文号或内部文档ID获取。
- 版本链查询：获取替代关系、发布日、生效日、失效日和当前状态。
- 正文与定位：返回条款、章节、页码或段落定位、来源URL、来源单位及审校状态。
- 变更同步：新增、修订、撤回和删除必须触发知识版本与索引版本变更。

输出包括当前版本、有效状态、要点、变化、适用条件、条款引用和复核事项。当前样例含一份经国务院官网核验的公开现行法规，以及用于展示版本比较的虚构材料；两者必须在来源性质和界面中明确区分。

以下事项不得由Agent自行完成：政策最终适用认定、实时空域许可判断、适航结论、主管部门解释和行政审批。

## 4. AG-025智能客服Agent

业务系统必须在服务端传入可信身份：租户、用户主体、角色和授权范围。请求正文中的自报身份不得用于鉴权。

CustomerServiceDataPort最少提供FAQ、订单、商品和服务查询；CustomerConversationPort提供会话读取、摘要保存和并发版本控制；人工转接回调提供目标队列、优先级、原因、已确认信息和待处理事项。

工作流固定保留：加载会话上下文、识别意图、必要追问、调用知识与业务工具、重排依据、按路由矩阵调用专业业务Agent、校验证据充分性与问题回答覆盖、评估订单数据时效、生成答复与路由、判断人工介入、保存会话状态。订单查询必须以唯一订单号和可信身份共同约束；不得猜测、替换或跨用户读取订单。

专业Agent协同必须返回目标Agent、真实执行状态、业务摘要和子链路编号。当前工程只允许路由至已注册样例：产品选型与比较至AG-001，政策法规及标准至AG-012，运营指标分析至AG-027。设备操作、订单履约、飞行服务等未注册专业能力不得伪装成已协同完成，应转为补充信息或专业人工处理。子Agent要求补充条件或人工复核时，AG-025必须原样保留该状态。人工客服转接仍只生成结构化建议，直至业务系统提供正式转接回调。

知识答复必须由与用户问题直接匹配的关键词、业务数据或专业Agent结果支撑，不得只因同属一个板块就返回泛化答案。输出必须分别记录用户所问、已有回答和仍待核实事项；未覆盖的退款时限、物流原因、发票办理等问题不得标记为完成。订单场景必须返回数据更新时间、距查询时点天数、是否存在承诺时限和异常判断；陈旧记录只作为历史线索，不得表述为实时状态。

以下事项不得由Agent自行完成：退款、改价、处罚、信用调整、授信审批、承保、正式投诉结案或绕过人工处理。

## 5. 可观测与验收

每次调用记录Agent、端口、模型、Embedding、重排、索引与知识目录版本；记录各节点耗时、Token、引用覆盖、内容支撑度、降级与错误，不记录API Key或不必要的用户正文。

验收分三层：

1. 确定性工程回归：固定黄金集与门禁，可重复执行。
2. 真实在线模型抽样：观察模型波动、耗时、Token和内容支撑度，发现项必须进入整改。
3. 甲方正式验收：使用授权知识、正式接口、业务专家答案和目标环境指标。

失败项按“定位责任环节—关联修复版本—全量回归—复测关闭”处理；不得只重跑失败题后直接关闭。

## 6. 切换步骤

1. 冻结端口字段、身份传递、错误码和超时约定。
2. 在隔离环境导入授权知识，核验版本、权限、撤回和删除同步。
3. 用甲方AI中台替换模型、Embedding和重排适配器。
4. 接入可信业务数据、会话存储和人工转接回调。
5. 重建正式黄金集并完成三层验收。
6. 灰度发布；出现越权、失效证据、连续降级或门禁阻断时停止放量并回退。
