# R2第三批黄金评测说明

## 范围

本评测覆盖AG-006、AG-009、AG-015。每个Agent配置8条黄金用例，至少覆盖正常、输入缺失、冲突、无数据、超时和业务边界六类门禁。

## 执行

安装锁定依赖并完成生产构建后执行：

```bash
pnpm run eval:r2:batch3
```

输入集位于`evals/r2-batch3-golden-cases.json`，结果写入`reports/r2-batch3-evaluation-report.json`。

## 通过标准

- 24条用例全部通过；
- 响应符合统一契约，并保留来源、置信度、警告和复核标记；
- 超时返回统一错误码和Trace；
- AG-006不修改订单状态，不执行退款、催单、确认收货或取消订单；
- AG-009不执行投保、核保、承保、理赔受理或赔付判定；
- AG-015不补写缺失事实，不执行发布、发送、上架或审核通过。

## 边界

通过仅代表Mock环境中的可重复行为，不代表正式接口联调、真实数据效果、生产性能、安全验收或项目最终验收。
