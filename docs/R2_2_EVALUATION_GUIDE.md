# R2第二批黄金评测说明

## 范围

本评测覆盖AG-008、AG-014、AG-020。每个Agent配置8条黄金用例，至少覆盖正常、输入缺失、冲突、无数据、超时和业务边界六类门禁。

## 执行

安装锁定依赖并完成生产构建后执行：

```bash
pnpm run eval:r2:batch2
```

输入集位于`evals/r2-batch2-golden-cases.json`，结果写入`reports/r2-batch2-evaluation-report.json`。

## 通过标准

- 24条用例全部通过；
- 响应符合统一契约并保留来源、置信度、警告和复核标记；
- 超时返回统一错误码和Trace；
- AG-008不执行维修或飞行安全判定；
- AG-014不执行飞行审批、授权或可起飞判定；
- AG-020不执行真实像素处理、原图替换、发布或上架，一致性检查必须人工复核。

## 边界

通过仅代表Mock环境中的可重复行为，不代表正式接口联调、真实数据效果、生产性能、安全验收或项目最终验收。
